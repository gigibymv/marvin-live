# Landing typefaces

The Marvin landing serves its own copies of Geist and Newsreader. The declarations in `components/marvin/Homepage.css` use landing-specific family names so they do not change the workspace theme.

Downloaded from the official Google Fonts CDN on 2026-10-21. These are normal-style Latin WOFF2 variable fonts, declared for weights 400–600. Newsreader also retains its optical-size axis.

- Geist v5: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFWNOITd.woff2
- Newsreader v26: https://fonts.gstatic.com/s/newsreader/v26/cY9AfjOCX1hbuyalUrK4397yjIJFJpc.woff2
- CSS source: https://fonts.googleapis.com/css2?family=Newsreader:opsz,wght@6..72,400..600&family=Geist:wght@400..600&display=swap
